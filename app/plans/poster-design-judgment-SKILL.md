# Poster Design Judgment

## Core philosophy

Do not apply a style. Apply a process: **identify the problem, generate real
options, justify every visual decision, know which rules are load-bearing and
which are just convention, and check the result against the actual communication
goal before calling it done.**

Every design rule below passes through one test before it's used:

> **RULE → what purpose does it serve → does that purpose apply here → is it worth
> the trade-off → test the result.**

If you can't state the purpose a rule serves in this specific case, don't apply it
just because it's "professional." Conventions are tools, not laws — a small number
of things below are near-fundamental; almost everything else is context-dependent
by design, and should be presented to the user as a default that can be overridden,
not a hard rule.

## Non-negotiable fundamentals (apply these regardless of style)

1. **A stated communication objective.** What must the viewer understand, feel, or
   do? If the brief doesn't give you enough to answer this, ask, or state your
   assumption explicitly before proceeding.
2. **Audience and viewing context.** Who sees it, where, at what distance, for how
   long (a wall poster viewed for seconds vs. a feed image viewed for a fraction of
   a second vs. a printed handout someone holds and reads).
3. **Intentional hierarchy.** The viewer should encounter information in the order
   the brief needs — achieved through scale, weight, color, position, isolation, or
   contrast (any combination; no fixed ratio is required — "hero must be exactly 3x
   subhead" is not a real rule, don't invent or follow one).
4. **Legibility at the real viewing size and distance**, not just on-screen at
   generation time.
5. **A concept that can be stated in one sentence**, distinct from a style
   description. "The poster visualizes momentum building toward a single point" is
   a concept. "Dark background with a gold gradient and some particles" is not — it's
   a decoration list standing in for a concept.
6. **Every major visual element earns its place.** If removing an element doesn't
   make anything worse, cut it. (Also watch the opposite failure — don't strip
   something purely because minimalism feels more "premium"; that's a style
   preference, not an editing decision.)

## High-value practices (use by default, override with a stated reason)

- Typeface choice motivated by the concept and audience, not left at whatever
  default the tool reaches for. Ask: what personality does this typeface carry, and
  does that fit the message? Contrast of *category* (a display face against a quiet
  workhorse) usually reads more "designed" than two similar grotesques at different
  weights.
- Deliberate line breaks, spacing, and alignment in the headline — don't accept
  automatic text wrapping as a design decision.
- Negative space treated as structural, not leftover.
- A grid or spatial system *when it helps this composition* — 12 columns is one
  common convention, not a requirement; simpler 2–4 division structures or
  intentionally non-modular layouts are equally legitimate depending on the concept.
- Iteration: generate a few genuinely different conceptual directions before
  polishing any single one. Converging on one safe direction immediately is itself
  a slop symptom.
- Self-critique before presenting: "would I approve this because it's effective, or
  because it looks impressive?"

## Context-dependent techniques (neither good nor bad by default)

Symmetry vs. asymmetry, minimalism vs. maximalism, serif/sans pairing choices,
photographic vs. illustrated imagery, flat vs. dimensional rendering, restrained
vs. saturated color, grid-based vs. collage/brutalist structure, 2–3 color
palettes vs. many colors. Each is correct when the concept and audience call for
it, wrong when defaulted into without a reason. **Never flag any of these, on
their own, as a quality signal in either direction.**

## Explicitly rejected as false rules

Do not use these as if they were established design science — they are either
invented, mislabeled, or contested folklore:

- Fixed numeric ratios presented as universal law: "hero 3x subhead," golden-ratio
  (1:1.618) layout requirements, "25% negative space per quadrant," "2–3 colors
  max," "limit to 2 fonts." Any of these can be a reasonable *default suggestion*
  for a specific brief — never a rule applied automatically.
- "Perfect symmetry = AI slop" and "asymmetry = elite." Both directions of this
  claim are style preference dressed as objectivity.
- "Type-High quality" as a synonym for elite typography. This is a mislabeled
  term — "type high" is an actual letterpress measurement (0.918in, the standard
  height of metal type), unrelated to design quality. Don't use it, and don't let
  it stand if a reference document uses it that way.
- Fabricated confidence percentages ("Typographic Systemization: 95%") for
  anything without a stated measurement method. Use plain qualitative language
  instead: strong / weak / uncertain, needs human review.
- "WCAG compliance" as a general poster requirement. WCAG is a *web content*
  accessibility standard. Apply its contrast-ratio logic when the poster is
  digital/on-screen; for print, judge legibility against real viewing distance,
  lighting, and print contrast instead of quoting a web standard.
- "Print-safe hex codes." Hex is an RGB notation; RGB and CMYK are different color
  spaces. Print production needs actual color-management/ICC awareness, not a hex
  code sanity check.
- Any single historical school (Swiss/Zurich, Basel, Bauhaus, etc.) treated as the
  universal definition of "serious" or "professional" design. They're specific,
  excellent traditions with their own internal standards — not a general law
  overriding every other tradition (brutalist, maximalist, protest/DIY, editorial,
  etc.) also listed as legitimate.
- Invented pseudo-metrics ("grid strictness index" or similar) presented as if
  they were validated measurements. Fine as an internal heuristic label; never
  presented as evidence-backed.

## AI-slop diagnostic (branching, not a flat checklist)

Don't run one universal checklist — first identify what tradition/style the poster
is working in, then judge it by that tradition's own standards. A maximalist or
brutalist poster will "fail" a minimalist checklist by design; that's not slop,
that's a different tradition.

Real, tradition-agnostic slop symptoms:

1. **Semantic mismatch** — imagery matches the subject noun but not the actual
   message (a generic person in front of a globe for "leadership conference").
2. **Decorative substitution** — glow, particles, gradients, or grain added to
   *look* more designed, with no communicative job.
3. **Unmotivated complexity or unmotivated simplicity** — both directions of
   laziness: busy because the tool could generate more, or bare because emptiness
   felt safe. Either way, ask what the choice is for.
4. **Generic composition with no contextual reason** — centered hero + headline
   above + text below + logo bottom-right isn't wrong, but if it appears with no
   reason grounded in this specific brief, that's the tell.
5. **Passive typography** — type placed into the layout rather than participating
   in its structure, rhythm, or meaning.
6. **The swap test** — could this exact layout be reused for a different
   client/headline with no change? If yes, it's underspecified to this brief.
7. **Uniform confidence** — every element rendered with the same polish/weight, no
   deliberate variation in what gets more attention than the rest.

## Reference-image workflow (influence, not replication)

When a reference image is provided, decompose it into layers **before** generating
anything new:

1. **Content** — what is literally depicted (subject, objects). This is the
   highest-risk-to-copy layer — do not carry it into the new output.
2. **Structure** — how the content is organized (dominant/secondary zones, margins,
   scale relationships, overlaps).
3. **Formal language** — geometric/organic, dense/sparse, flat/dimensional,
   restrained/expressive.
4. **Perceptual behavior** — where the eye enters, how it moves, what creates the
   focal point.
5. **Meaning** — *why* those choices work together (e.g., "large-scale type plus a
   restricted palette plus disproportionate cropping reads as institutional
   authority under tension" — not just "dark blue, big text, grain").

Extract the **principle**, not the subject. Test: state in one sentence what the
reference is doing structurally. If that sentence names a subject ("a poster of a
dancer"), you're heading toward replication. If it names a relationship or
mechanism ("tension between a soft photographic form and rigid geometric type"),
you're heading toward legitimate influence. Deliberately vary subject,
composition, scale relationships, typography, and color logic when building the
new piece — changing surface details (just the color or just the font) while
keeping the same structure and content is still replication.

Note on legality: decomposing style from subject reduces copying risk. It does not
guarantee legal safety on its own — avoid reproducing distinctive expressive
arrangements, don't rely on "I extracted the DNA" as a legal shield.

## No-reference workflow

When there is no reference image, don't jump straight to "be creative." Work
through:

1. **Turn the brief into a problem statement**: "A viewer who is [audience] needs
   to understand/feel [X] and remember/do [Y]." If the brief can't support this
   sentence, ask a clarifying question rather than guessing.
2. **Generate 2–4 genuinely different conceptual directions** (not palette
   variations of the same idea) — e.g., a symbolic/metaphor-led direction, a
   typography-led direction, a documentary/photographic direction, a
   structural/grid-led direction. State the reasoning for each in one sentence.
3. **Kill weak directions before polishing anything.** Reject a direction if the
   metaphor is obscure, the composition is generic, the concept needs more than
   one sentence to explain, or the imagery reads as stock.
4. **Develop only the strongest direction** — spend detailed effort (type, color,
   imagery, texture) after the concept is chosen, not before.
5. **Self-critique against the brief's objective**, not against "does this look
   designed."

## Creativity, operationalized

Reject "make it creative/unique/professional/modern" as unusable instructions.
Replace with a checklist:

- **Specificity** — could this exact design only serve this exact brief?
- **Relevance** — is the unexpected element actually connected to the message
  (novelty without relevance gets attention but doesn't communicate)?
- **Coherence** — do the unusual choices belong together, or are they scattered?
- **Restraint** — does more novelty past this point add noise rather than value?
- **Communication gain** — does the creative choice actually improve
  understanding, attention, emotion, or recall — not just impressiveness?

For visual metaphor specifically: aim for *moderate* incongruity — enough
unexpectedness to create curiosity, enough relevance that it's still
interpretable. Total literalism is sometimes correct (safety notices, medical
information, urgent announcements); total abstraction that requires an insider
explanation is a failure, not sophistication.

## Before presenting any poster, run this checklist

- **Purpose** — can you state what this poster needs to accomplish in one
  sentence? If not, stop and clarify.
- **Concept** — one-sentence visual idea, distinct from a style/decoration
  description.
- **Hierarchy** — does the intended first/second/third read actually happen at the
  real viewing size?
- **Typography** — chosen for a reason, not defaulted; line breaks and spacing
  deliberate.
- **Composition** — every major element's position justified; negative space
  intentional.
- **Color** — each major color doing a job, not just "3 colors because that's the
  rule."
- **Distinctiveness** — swap test: could this exact layout serve a different
  client/headline unchanged? If yes, revise.
- **Slop check** — run the branching diagnostic above, judged against this
  poster's own tradition, not a universal minimalist standard.
- **Editing** — anything that can be cut without making the result worse?
- **Final question** — would this be approved because it's effective, or because
  it merely looks impressive? If you can't tell the difference, that's the signal
  to revise, not ship.
